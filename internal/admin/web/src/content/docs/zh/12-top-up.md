## 充值步骤

### 1. 进入钱包

登录控制台，点左侧菜单的「钱包 / 账单」，或直接访问 [api.novadiffusion.com/app/billing](https://api.novadiffusion.com/app/billing)。

### 2. 选择充值金额

预设选项或自定义金额，**最低 $1** 即可开始使用。

### 3. 选择支付方式并完成支付

默认走**支付宝**，也可改用**银行卡**。按页面引导完成支付后，余额会自动到账，无需联系客服。

> **余额不足会怎样？** API 请求会返回 `402 Payment Required` 错误，客户端会显示「请求失败」。建议在控制台开启低余额提醒，避免影响正常使用。

## 计费方式

按 Token **实时计费**：每次请求结束后，根据本次的输入 Token 数 × 输入单价 + 输出 Token 数 × 输出单价，从余额中扣除。不同模型单价不同，具体以控制台的 [价格](/docs/pricing) 页面为准。

> 充值完成后，就可以去 [接入客户端](/docs/codex-cli) 开始使用了。
